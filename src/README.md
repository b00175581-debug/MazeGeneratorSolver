
# Maze Generator and Solver

## Project Description

This project is a Java desktop application that generates
random mazes and finds a path through them.

The application uses Depth-First Search (DFS) to generate
mazes and Breadth-First Search (BFS) to solve them.

## Technologies

- Java
- Java Swing
- Stack
- Queue
- Graph Algorithms
